# 🥠 Biscoito da Sorte

Aplicativo simples de Biscoito da Sorte desenvolvido com **React** e **JavaScript**.

## 💻 Tecnologias utilizadas
- React
- JavaScript
- HTML
- CSS

## 🚀 Funcionalidade
O usuário clica no botão e recebe uma frase aleatória de motivação/sorte.
